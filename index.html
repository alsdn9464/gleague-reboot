    마감일이 빠른 목표부터 수입이 차례로 채워지는 것으로 계산해요.
    날짜를 누르면 그날 수입을 입력할 수 있어요. 진할수록 수입이 많은 날이고, ▲▼는 그 달 일평균 대비예요.

        GitHub 자동 저장
        입력·수정할 때마다 저장소 파일에 자동 반영하고, 열 때 자동으로 불러와요.
        토큰 만드는 법
        GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate. 저장소는 이 저장소만 선택하고, 권한은 Contents: Read and write 하나만 주세요. 토큰은 이 브라우저에만 저장돼요. 저장소가 공개면 수입 내역도 공개되니 비공개 저장소를 권해요.
        백업
        데이터는 이 브라우저에 저장돼요. 기기를 바꾸기 전에 백업하세요.
